# Customer Segmentation Lab

An end-to-end customer segmentation project using the popular Kaggle **Mall Customers** dataset schema. The project follows CRISP-DM and uses K-Means clustering to turn customer demographics and spending behavior into actionable segments.

The app runs immediately with a deterministic built-in demo dataset. To use the original Kaggle data, download `Mall_Customers.csv` from the [Customer Segmentation Dataset](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python) and place it at `data/Mall_Customers.csv`.

## Run locally

```bash

source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL printed by Streamlit.

## What the dashboard includes

- Dataset preview, schema, missing-value checks, and EDA
- Elbow curve and silhouette-score selection of `k`
- Interactive 2D cluster view with customer filters
- Segment profiles with interpretable names and business actions
- Cluster-size and spending visualizations
- Downloadable labeled customer data

## Architecture

`app.py` is the interactive presentation layer. `src/segmentation.py` owns data loading, cleaning, feature engineering, model selection, fitting, profiling, and interpretation. The implementation accepts either the Kaggle CSV or a reproducible fallback generated by `src/data.py`.

## Model

The default feature set is Annual Income, Spending Score, Age, and encoded Gender. Numeric features are standardized with `StandardScaler`, then K-Means is evaluated over `k=2..8` using inertia and silhouette score. The selected `k` maximizes silhouette score, with the elbow used as a sanity check.

## Reproducibility

The fallback data and K-Means use fixed random seeds. The fallback is not a claim about Kaggle results; it exists so the demonstration is runnable without external credentials. For a report using the original benchmark data, replace the CSV and rerun the dashboard.
